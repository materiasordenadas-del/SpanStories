# Fachada colonial caribeña (reservada para otro proyecto)

Hecha para el Hotel Palma Real el 30-09-2026 y retirada: el usuario quiere el hotel 5 estrellas
moderno. Se conserva para reutilizarla en otro escenario SpanStories (casa colonial, hotel boutique).

- `FachadaColonial.js`: piezas (ventana de arco, balconera con postigos, balcón de madera con
  tejadillo, buganvilla, farol, portón de dos hojas, alero y cubierta de teja). Va en `objetos/`.
- `fachada-colonial-escena.js`: el constructor `fachada(group)` tal como estaba en HotelWorld.js
  (usa `add`, `block`, `text`, `palms`, `crearArco`, `crearMuroConHuecos`, `crearPisoHotel`...).
- `FACADE.js`: las constantes con nombre que usa (pegar en `engine/dimensions.js`).
- Colores extra que usa: coral, lime, tile, tileDark, iron, bougain (ver COLORS del hotel).

Referencias: Casa San Agustín y Sofitel Legend Santa Clara (Cartagena): muros encalados,
piedra coralina, balcones de madera, arcadas.
