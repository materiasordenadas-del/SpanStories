# SpanStories — actualización conjunta del 3 de noviembre de 2026

Se reúnen en un mismo repositorio las mejoras locales de la aplicación educativa, el visor de ciudades, Story Studio, Atlas/Generador de Mundos y las herramientas de Blender. Las ramas y archivos de trabajo originales se conservan; esta integración es una rama nueva de publicación.

## Organización

- Raíz: aplicación educativa, lector, cuentas, práctica y conocimiento léxico.
- `SpanStories-Ciudades/`: motor del visor vigente, recursos de ciudades y conexión con el generador.
- `features/story-studio/`, `app/`, `docs/story-studio/`: estudio narrativo integrado y documentación.
- `Generador-Mundos/`: Atlas · Estudio de lugares 0.17.0, generación, biblioteca y estilos compartidos.
- `herramientas/`: Texture Painter, Rig Labial Bendy, herramientas de movimiento, GLB, Cara Viva y expresiones corporales.

## Uso

Requiere Node 20.9 o posterior y Python para los servicios locales. En la raíz: `npm ci` y `npm run dev:visor`. La entrada vigente es `http://localhost:3000/mundo/piloto-lexico`; desarrollo se abre con `?modo=desarrollo`. El puerto 8877 sirve internamente el motor. No abrir otras versiones del visor.

Para Atlas: `cd Generador-Mundos`, `npm ci`, `npm run dev`. El generador conserva su carpeta original como fuente local; esta publicación reúne sus fuentes en GitHub. La distribución integrada permite que `SpanStories-Ciudades/serve.py` encuentre `Generador-Mundos/` por su ruta relativa.

Las herramientas Blender tienen sus propias instrucciones y manifiestos. No se incluyen complementos comerciales de terceros, archivos `.blend`, cachés, respaldos, paquetes ZIP históricos ni entregas temporales. Se conservan los modelos y recursos de ejecución inventariados. No se han modificado ni guardado escenas de Blender.
